My mechanic is the Overwatch mechanic from Star Wars: Zero Company. It is just a enemy scanner to find a target and auto shoot when an enemy enters line of sight.

My code uses no interface: DamageField talks directly to the concrete Health class, though an IDamageable interface would be the natural addition if you need one. It also doesn't use Time.deltaTime; both the shot rate and the placement cooldown compare against Time.time timestamps (nextShotTime, nextPlaceTime), and the field's lifetime is handled by Destroy(gameObject, lifetime). For initialization, Health.Awake sets starting health and FieldPlacer.Awake grabs the main camera, DamageField.Init is called right after the field is instantiated to pass in the shooter, and DamageField.Start runs last to schedule the field's self-destruction.
